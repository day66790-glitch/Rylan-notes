# 🐳 Rylan's note

一个基于大模型与浏览器语音 API 的智能语言助手，专为**传媒与新闻专业**学生打造。

## ✨ 核心功能
- **🎙️ 实时同声传译**：支持多语种、多口音（如马来西亚英语、印度英语）实时识别与自动翻译。
- **📖 传媒术语库**：内置 B-roll、Stand-up 等专业词汇，支持用户自定义术语注入翻译 Prompt，告别机翻尴尬。
- **📝 智能笔记系统**：支持时间戳记录、Markdown 格式、数学公式（LaTeX）、表格渲染、图片上传（Base64）。
- **🤖 真实大模型接入**：支持 DeepSeek、OpenAI、Claude 等主流大模型 API 真实调用。
- **🎨 Apple 风格 UI**：纯前端实现，毛玻璃特效（Glassmorphism），支持暗黑/白天平滑切换。

## 🛠️ 技术栈
- **纯原生前端**：HTML5 + CSS3 + Vanilla JavaScript (无复杂框架)
- **样式**：Tailwind CSS (CDN)
- **API 服务**：Web Speech API / OpenAI Whisper / DeepSeek
- **部署**：Netlify

## 🚀 本地运行
1. 克隆仓库：`git clone https://github.com/day66790-glitch/Rylan-notes.git`
2. 使用 VS Code 打开文件夹。
3. 使用 Live Server 插件打开 `index.html`。
4. 在个人设置中填入你的大模型 API Key 即可使用。
