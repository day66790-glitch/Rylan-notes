    使用提示

    • · 提供商与 Key 会一起保存在当前浏览器，清除浏览器数据后会丢失，需要重新填写。
    • · 不要把 Key 分享给他人；公共电脑上使用后请点击「删除已保存的 Key」。
    • · 可前往 DeepSeek 开放平台、OpenAI、Anthropic、Google AI Studio 或阿里云百炼控制台创建 API Key。
    • · 浏览器直连第三方 API 可能受 CORS 限制；若失败，请改用支持跨域的代理地址或在本地服务中转发。
